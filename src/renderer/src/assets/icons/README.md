# 图标素材库说明

「转格式软件」黑金调律者风格图标集，全部为原创矢量 SVG，无照片/第三方素材。

## 目录

| 目录         | 内容                                                                                                                          | 尺寸   | 风格                                |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------- | ------ | ----------------------------------- |
| `logo.svg`   | 应用徽记：刻度环 + 蜂窝六边形 + 转换双箭头 + 中心菱形                                                                         | 64×64  | 黑金蚀刻                            |
| `formats/`   | 23 个格式图标砖（JPG/PNG/WebP/GIF/SVG/BMP/TIFF、PDF/DOCX/XLSX/TXT/MD/EPUB、MP3/WAV/FLAC/MP4/MOV/MKV、ZIP/7Z/RAR + 通用 FILE） | 64×64  | 深底砖 + 金边 + 类别图形 + 衬线字母 |
| `ui/`        | 13 个界面图标（添加/文件夹/转换/下载/成功/失败/关闭/设置/历史/信息/删除/箭头/菱形）                                           | 24×24  | 金色描边 1.5px，透明底              |
| `ornaments/` | 6 个调律者纹样（蜂窝平铺、刻度环、空状态大纹样、角饰、分隔线、单格徽记）                                                      | 见文件 | 金线蚀刻                            |

## 使用要点

- **配色**：所有金色均为固定色值（主金 `#C9A227`），若需随主题变化，把 `stroke="#C9A227"` 替换为 `stroke="currentColor"` 后用 CSS 控制
- **缩放**：图标可任意缩放；格式砖缩至 36px（列表）/ 24px（小徽章）仍可辨认
- **镜像**：`corner-ornament.svg` 为左下角方向，其余三角用 `transform="scale(-1,1)"` / `scale(1,-1)` / `scale(-1,-1)` 镜像
- **平铺**：`honeycomb-pattern.svg` 可直接作 `<pattern>` 或 CSS `background-image`，建议整体透明度 7%–16%
- **新增格式图标**：复制任一 `format-*.svg`，替换中部类别图形与底部文字即可，保持砖底与描边不变
